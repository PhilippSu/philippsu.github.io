# Ye Su — Portfolio

Personal portfolio for robotics and mechatronics opportunities in Germany and Europe.

## Local preview

The site is plain HTML and CSS. Start any static file server in the repository root, then open index.html through that server.

## Structure

- index.html — page content and semantic structure
- assets/css/style.css — responsive visual design
- assets/images/projects/ — future project imagery
- assets/images/profile/ — future profile imagery
- assets/documents/ — CV and other downloadable documents

The CV link expects assets/documents/CV_Ye_Su.pdf. Add the real file when it is ready.
